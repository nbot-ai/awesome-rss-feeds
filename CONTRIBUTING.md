# Contributing to Awesome RSS Feeds

Thank you for your interest in contributing! This document provides guidelines for contributing to this curated list.

## How to Contribute

### Adding a New RSS Feed

1. **Fork** this repository
2. **Add** your feed to the appropriate category in `README.md`
3. **Follow** the table format:
   ```markdown
   | Source Name | `https://example.com/feed/` |
   ```
4. **Submit** a Pull Request

### Quality Requirements

Before submitting, ensure the feed meets these criteria:

- [ ] **Active**: Published content within the last 30 days
- [ ] **Reliable**: Consistent uptime (no frequent 404s or timeouts)
- [ ] **Valid RSS/Atom**: Properly formatted XML feed
- [ ] **Quality Content**: Original, well-written content (no spam or scraper sites)
- [ ] **Working URL**: The feed URL must be accessible

### Suggesting New Categories

1. Open an **Issue** first to discuss the new category
2. Explain why this category would be valuable
3. Suggest at least 5 feeds that would fit in this category

### Reporting Broken Feeds

If you find a broken or outdated feed:

1. Open an **Issue** with the title: `[Broken Feed] Source Name`
2. Include the current URL
3. If available, suggest the new/updated URL

## Pull Request Guidelines

- One feed per PR (unless adding a new category)
- Keep the alphabetical order within categories
- Use the exact format shown in the README
- Include a brief description of the source in your PR

## Code of Conduct

- Be respectful and constructive
- No spam or self-promotion without value
- Focus on quality over quantity

## Questions?

Open an issue if you have questions about contributing.
