## Contributing

Contributions are welcome! Please read the [contribution guidelines](CONTRIBUTING.md) first.

### How to Add a Feed

1. Fork this repository
2. Add your RSS feed to the appropriate category in `README.md`
3. Make sure the feed is:
   - Active (published content within the last 30 days)
   - Reliable (consistent uptime)
   - High-quality content
4. Submit a Pull Request

### Suggesting New Categories

If you think a new category would be valuable, please open an issue first to discuss it.
